# Гами — тренажер сенсорного набору

Браузерний тренажер набору наосліп десятьма пальцями **українською (ЙЦУКЕН)** та **англійською (QWERTY)**.
Робота для [Typing Race 2026 Hackathon](https://stszu.github.io/Typing-Race-2026-Hackathon/).

- **Демо:** https://apteka95video-source.github.io/gamy-typing-trainer/
- **Репозиторій:** https://github.com/apteka95video-source/gamy-typing-trainer

Головна ідея — словники як гами на фортепіано: короткі повторювані рухи, одна мета на вправу,
нова складність лише після засвоєння попередньої. Точність має пріоритет: швидкість ніколи не
зараховує вправу сама.

## Запуск

Це статичний сайт без збирання й без залежностей.

```bash
npm start            # або: node scripts/serve.mjs  → http://localhost:8000
```

Без Node.js підійде будь-який статичний сервер, наприклад `python3 -m http.server 8000`.
Змінні середовища, ключі API та платні сервіси не потрібні, тому файлу `.env.example` немає.

## Перевірки

```bash
npm run check        # контрольні суми словників + 64 модульні тести (лише Node.js ≥ 20)
npm install          # лише для наскрізних тестів: Playwright і axe-core
npx playwright install chromium
npm run test:e2e     # 27 сценаріїв у справжньому браузері
```

Якщо Chromium від Playwright недоступний, можна взяти встановлений Chrome: `PW_CHANNEL=chrome npm run test:e2e`.
Результати останнього прогону — у [docs/test-results.md](docs/test-results.md); ті самі перевірки
виконує GitHub Actions на кожен коміт.

## Три етапи навчання

| Етап | Що набирає учень | Мета |
|---|---|---|
| **1. Клавіатурні гами** | послідовності клавіш без змісту: `фіва олдж`, `ждло авіф`, `asdf jkl;`, дзеркальні пари, чергування рук, вертикальні переходи, один палець на кількох клавішах, Shift, знаки, цифри | правильний палець і повернення на домашній ряд |
| **2. Слова з вивчених клавіш** | справжні слова мови, усі символи яких уже відкриті на етапі 1; окремі вправи на повтори клавіші, рух одним пальцем між рядами, чергування рук, апостроф, дефіс, великі літери, `ґ є ї і` | рухи стають словами |
| **3. Академія** | 10 модулів: найчастіші біграми й триграми, закінчення та префікси, переходи одним пальцем, чергування рук і перекати, подвоєння, знаки й числа, речення, абзаци, темпові серії | швидкість без втрати точності |

Курс лінійний: гами уроку → слова уроку → наступний урок → Академія. Українською 23 уроки й 225 вправ,
англійською 21 урок і 206 вправ. Клавіші відкриваються по дві. Докладно — [docs/pedagogy.md](docs/pedagogy.md).

**Залік.** Спробу зараховано, якщо точність не нижча за поріг етапу (95 / 96 / 97 %); вправу завершено
після трьох успішних спроб поспіль. Швидкість вимагається лише в модулі «Темпові серії» — і лише разом
із точністю. Усі пороги змінюються в налаштуваннях (точність — не нижче 90 %).

**Залік без підказок.** Під час залікової спроби на екрані немає клавіатури й підсвічування наступної
клавіші. Схема пальців показується перед вправою; підказка є лише в режимі «Тренування», результат якого
не зберігається й на прогрес не впливає.

## Метрики

| Метрика | Формула |
|---|---|
| Швидкість, зн/хв (SPM) | `60 · N / T`, де `N` — символів у вправі, `T` — секунди від першого до останнього натискання |
| Точність | `(N − E) / N · 100 %`, де `E` — усі помилкові натискання, **включно з виправленими** |
| WPM | `SPM / 5` |
| Нерівномірність ритму | `σ / μ` пауз між чистими натисканнями |

Після спроби: швидкість, точність, кількість помилок, час, ритм, порівняння з попередньою спробою й
особистим рекордом, помилки за символами (і що саме натискалося), найповільніші переходи, графік ритму
та **одна конкретна наступна дія** за фактичними помилками — наприклад, вправа на клавішу, де помилок
було найбільше.

## Що ще є

- початкова діагностика або вибір рівня; для досвідчених — вільний доступ до всіх вправ;
- заняття на 15–25 хвилин: розігрів, цільова навичка, закріплення, справжній текст;
- адаптивна вправа «Слабкі місця» з клавіш і переходів, де користувач помиляється чи гальмує;
- статистика: динаміка, карта помилок на клавіатурі, слабкі клавіші, повільні переходи;
- зупинка на помилці або виправлення клавішею Backspace; помилка рахується в обох режимах;
- вставка з буфера відхиляється; неправдоподібно швидкий набір не зараховується;
- перевірка розкладки до старту; Alt, AltGr, dead keys та IME не ламають спробу;
- експорт та імпорт профілю у файл; робота без мережі після першого завантаження (PWA);
- світла й темна теми, розмір тексту вправи 20–44 px, вимкнення анімацій і звуку;
- керування лише з клавіатури, видимий фокус, помилка позначається не лише кольором.

## Архітектура

```text
index.html, assets/styles.css   оболонка та стилі
src/core/                        ядро без DOM — його ж імпортують тести й скрипти збирання
  layouts.js                     фізичні клавіші, розкладки, палець кожної клавіші
  engine.js                      автомат набору однієї спроби
  metrics.js                     SPM, точність, ритм, залік, перевірка правдоподібності
  analysis.js                    розбір спроби, статистика клавіш і переходів, рекомендація
  adaptive.js                    генератор вправ на слабкі місця
  progress.js                    порядок вправ, відкриття, серії спроб
  storage.js                     профіль у localStorage, експорт та імпорт
src/ui/                          екрани: trainer.js (вправа), views.js (решта), keyboard.js
scripts/
  build-data.mjs                 dictionaries/ → data/derived/   (очищені словники, n-грами)
  build-curriculum.mjs           data/derived/ + data/texts/ → data/curriculum/
  checksums.mjs                  контрольні суми сировини
dictionaries/                    незмінні знімки джерел із ліцензіями та manifest.json
data/derived/                    похідні словники та звіт обробки
data/curriculum/                 уроки й модулі Академії
data/texts/                      власні речення й абзаци (CC0)
data/filters/                    контентний фільтр і доповнювальні списки
tests/                           модульні тести; tests/e2e/ — наскрізні
```

Сервера немає. Профіль зберігається в `localStorage` браузера. Програма не робить запитів на сторонні
домени, не має аналітики й не використовує AI під час роботи.

## Обмеження

- Цільова платформа — комп'ютер із фізичною клавіатурою. На телефоні верстка коректна, вправи
  відкриваються, але повноцінний сенсорний набір на екранній клавіатурі не є метою.
- Програма перевіряє набраний символ, а не фізичну клавішу. Схема пальців для української подана за
  розкладкою «Українська (розширена)» Windows: апостроф ліворуч від `1`, `ґ` — AltGr+Г. На інших
  системах ці два символи можуть бути на сусідніх клавішах.
- Програма не контролює погляд і не використовує камеру. Підглядання стає зайвим завдяки побудові
  вправ і відсутності підказок під час заліку.
- Частотність рахується всередині слів. Частотність переходів між словами не оцінюється: для цього
  потрібен окремий корпус.
- Частотний список зібрано із субтитрів, тому лексика розмовна; попри фільтри, окремі рідкісні чи
  дивні слова можуть траплятися.
- Багатокористувацького змагання й рейтингу немає: усі результати — лише особисті й локальні.
- Профіль прив'язаний до браузера; перенести його можна файлом експорту.
