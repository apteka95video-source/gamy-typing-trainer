# Декларація використання AI

## У готовому продукті

AI **не використовується**. Програма не звертається до мовних моделей і не робить запитів на
сторонні домени. Усі вправи або зібрані заздалегідь детермінованими скриптами
(`data/curriculum/`), або генеруються локально в браузері за правилами (`src/core/adaptive.js`) зі
словника з відкритою ліцензією. Ключів API в репозиторії та клієнтському коді немає.

## Під час розробки

**Інструмент:** Claude Code (Anthropic), модель Claude Opus — AI-асистент у терміналі, який писав
код, тексти вправ і документи за завданням учасника. Учасник поставив завдання; проєктні рішення,
код, тексти й перевірки нижче виконав AI-асистент.

| Що зроблено з AI | Як перевірено |
|---|---|
| Архітектура, код ядра (`src/core/`), інтерфейс (`src/ui/`, `index.html`, `assets/styles.css`) | 64 модульні тести ядра та 27 наскрізних сценаріїв у Chrome (`npm run check`, `npm run test:e2e`); аудит axe-core і Lighthouse; перегляд знімків екранів у світлій і темній темах на 1440 px і 390 px |
| Скрипти обробки словників (`scripts/build-data.mjs`, `scripts/lib/hunspell.mjs`) | тест відтворюваності порівнює щойно зібрані файли із закоміченими побайтно; перевірка Hunspell звіряється на відомих словах; вагу n-грам тест перераховує незалежно; під час розробки переглянуто верхівку списків і відсіяні слова, за результатами доповнено фільтри |
| Метод вилучення російських слів з українського частотного списку | порівняно частку «російських» вживань для контрольних слів обох типів («не», «там» проти «ладно», «конечно»); тест перевіряє, що типові російські слова відсутні, а українські — на місці |
| Генератор курсу (`scripts/build-curriculum.mjs`): порядок клавіш, типи вправ, модулі Академії | під час розробки переглянуто повний текст усіх вправ обох мов; тест перевіряє для кожного варіанта кожної вправи етапів 1–2, що в ньому лише відкриті символи, а слова етапу 2 є в словнику |
| Речення й абзаци в `data/texts/` (оригінальні тексти, не з корпусів) | тест перевіряє, що кожен символ є в розкладці; тексти короткі й зібрані в одному місці, тож їх легко вичитати |
| Контентний фільтр і доповнювальні списки в `data/filters/` | кожне доповнювальне слово під час збирання перевіряється за Hunspell — невідоме слово зупиняє збирання |
| Тести й документація | тести запускаються локально та в GitHub Actions; цифри в документах узято з фактичних запусків |

## Чого AI не робив

- Не генерував слова для вправ: усі слова походять зі словників із відкритими ліцензіями або з
  переліку, перевіреного за Hunspell.
- Не оцінює користувача і не формулює рекомендації під час роботи програми: рекомендація — це
  правило в `src/core/analysis.js`, покрите тестами.

## Дані користувача

Тексти, які набирає користувач, і його прогрес нікуди не передаються — зокрема жодному AI-сервісу.
