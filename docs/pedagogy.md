# Навчальна модель

## Що таке сенсорний набір у цій програмі

1. Одна фізична клавіша — один визначений палець (таблиці — у продукті на сторінці «Метод і пальці»,
   у коді — `src/core/layouts.js`, перевіряються тестом `tests/layouts.test.mjs`).
2. Пальці стартують із домашнього ряду (`ФІВА ОЛДЖ`, `ASDF JKL;`) і повертаються на нього після
   кожного натискання.
3. Пробіл натискає великий палець, Shift — мізинець руки, протилежної літері.
4. Погляд лишається на екрані.
5. Швидкість нарощується лише після стабільної точності й рівного ритму.

Програма не стежить за поглядом і не заявляє про такий контроль. Підглядання стає зайвим через
побудову курсу: клавіші відкриваються по дві, кожна нова клавіша спершу відпрацьовується рухом
«домашня → клавіша → домашня», а під час заліку на екрані немає ні клавіатури, ні підказки.

## Словники як гами

Вправа — це не випадковий перелік слів, а короткий повторюваний руховий малюнок з однією метою.
Мету кожної вправи написано на її екрані: яка клавіша, який палець, який перехід.

Складність зростає в такому порядку:

```text
клавіша → пара клавіш → склади й морфеми → слова → слова зі знаками → речення → абзац → темпова серія
```

## Етап 1 — клавіатурні гами

Тексти цього етапу не є словами й позначені в інтерфейсі «Механіка: це рухи, а не слова».

| Тип вправи | Приклад (українська) | Приклад (англійська) |
|---|---|---|
| нова клавіша домашнього ряду | `ааа аа а ааа аа а` | `fff ff f fff ff f` |
| нова клавіша з поверненням на домашню | `аеа аеа аае ееа ае еа` | `ded ded dde eed de ed` |
| дві нові клавіші разом | `аеа оно ен не аеон онае` | `ded kik ei ie deki kide` |
| найчастіші пари літер із новими клавішами | `на на не не ні ні ен ен` | `he he hi hi is is ea ea` |
| гама зліва направо і назад | `фіва олдж … ждло авіф` | `asdf jkl; … ;lkj fdsa` |
| дзеркальні пари від країв до центру й назад | `фж ід вл ао ао вл ід фж` | `a; sl dk fj fj dk sl a;` |
| чергування рук | `фо іл вд аж оф лі дв жа` | `aj sk dl f; ja ks ld ;f` |
| ізоляція однойменних пальців | `аа оо вв лл іі дд фф жж` | `ff jj dd kk ss ll aa ;;` |
| рівний ритм у трьох темпах | орієнтири 80–110, 110–140, 140–180 зн/хв | те саме |
| вертикаль: домашній → верхній → нижній | `фйфяф іцічі вувсв акама` | `aqaza swsxs dedcd frfvf` |
| один палець на кількох клавішах | `ака ама аеа апа аиа` | `frf fvf ftf fgf fbf` |
| ряди цілком | `йцукен гшщзхї фівапр` | `qwert yuiop asdfg hjkl` |
| Shift | `Оо Лл Дд`, `Ао Оа Вл Лв` | `Jj Kk Ll`, `Fj Jf Dk Kd` |
| розділові знаки як окремі рухи | `ж-ж о?о ф!ф о:о` | `;-; ;?; a!a ;:;` |
| цифри | `ф1ф і2і в3в а4а а5а` | `a1a s2s d3d f4f f5f` |

У вправах на ритм залік залежить лише від точності: темп і нерівномірність ритму показуються як
орієнтир, щоб початківця не блокувала недосяжна швидкість.

### Порядок відкриття клавіш

- **Українська:** `а о` → `в л` → `і д` → `ф ж` → гами домашнього ряду → `п р` → `е н` → `и т` →
  `к г` → `м ь` → `у ш` → `с б` → `ц щ` → `ч ю` → `й з` → `я .` → `х ї` → `є ' ґ` → вертикальні
  переходи → один палець на кількох клавішах → Shift і `,` → знаки `- ? ! : ; "` → цифри.
- **Англійська:** `f j` → `d k` → `s l` → `a ;` → гами домашнього ряду → `g h` → `e i` → `r u` →
  `t y` → `o w` → `p q` → `n b` → `m v` → `c ,` → `x .` → `z '` → вертикальні переходи → один палець
  на кількох клавішах → Shift → знаки `- ? ! : "` → цифри.

Спершу домашній ряд, далі — пари клавіш дзеркальних пальців; частотніші літери йдуть раніше, щоб
слова з'являлися якомога швидше.

## Етап 2 — слова з уже вивчених клавіш

Слово потрапляє у вправу лише тоді, коли **всі** його символи відкриті. Це гарантує генератор
(`scripts/build-curriculum.mjs`) і перевіряє тест для кожного варіанта кожної вправи
(`tests/curriculum.test.mjs`, наскрізний тест читає слова з DOM).

У кожному уроці, де вже є з чого складати слова:

- **слова з новими клавішами** — найчастотніші слова, у яких є щойно відкрита літера;
- **найчастіші слова з відкритих клавіш** — найуживаніші слова мови, які вже можна набрати;
- **довші слова** — від шести літер, коли їх стає достатньо.

Окремі вправи: повтори тієї самої клавіші, рух одним пальцем між рядами, чергування рук, слова з
великої літери, слова з комою та крапкою, апостроф, дефіс, знаки `? ! : ;`, числа зі словами,
українські літери `ґ є ї і`.

Кожна вправа має кілька варіантів тексту; після кожної залікової спроби варіант змінюється, тому
три спроби поспіль — це три різні набори слів з однією метою.

Добір адаптується до користувача: вправа «Слабкі місця» (`src/core/adaptive.js`) бере клавіші з
найбільшою часткою помилок і найповільніші переходи з його статистики та добирає слова саме з ними —
знову лише з відкритих символів.

## Етап 3 — Академія

Окремий курс для кожної мови, 10 послідовних модулів:

1. **Найчастіші біграми** — 10 пар літер із найбільшою вагою.
2. **Найчастіші триграми** — 8 трійок.
3. **Закінчення, суфікси та префікси** — `-ing`, `-ed`, `-tion`, `re-`; `-ння`, `-ати`, `-ого`, `про-`, `при-`.
4. **Складні переходи одним пальцем** — найчастіші пари, які набирає той самий палець.
5. **Чергування рук і перекати** — слова з повним чергуванням рук і пари сусідніх пальців.
6. **Подвоєння літер**.
7. **Великі літери, розділові знаки й числа** — у справжніх реченнях.
8. **Речення**.
9. **Абзаци**.
10. **Темпові серії** — короткі серії найчастіших слів.

Вага біграми чи триграми — сума частот слів, у яких вона трапляється; її показано в назві й описі
вправи («№ 1 за частотою: трапляється у словах, що дають 6,2 % усіх слововживань»). Там само
названо пальці й характер руху: чергування рук, перекат, один палець.

Модуль завершено, коли зараховано всі його вправи; наступний модуль відкривається після попереднього.

## Критерії заліку

| Етап | Мінімальна точність | Вимога до швидкості |
|---|---:|---|
| 1. Гами | 95 % | немає |
| 2. Слова | 96 % | немає |
| 3. Академія | 97 % | лише «Темпові серії»: не нижче 150 зн/хв |

- Вправу завершено після **трьох успішних спроб поспіль**; невдала спроба обнуляє серію.
- Перевірка йде в такому порядку: правдоподібність набору → точність → (лише темпові серії) швидкість.
  Тому швидкість не може зарахувати вправу без точності.
- Усі значення змінюються в налаштуваннях; точність не можна опустити нижче 90 %.

## Зворотний зв'язок

Після спроби програма формулює рівно одну наступну дію за фактичними даними:

- найбільше помилок на одній клавіші → назва клавіші, її палець, що натискалося замість неї, і
  кнопка «Вправа на слабке місце»;
- помилки розкидані → «Знизь темп приблизно до N зн/хв», де N обчислено з поточної швидкості;
- у темповій серії бракує швидкості → найповільніший перехід і вправа на нього;
- спробу зараховано → скільки спроб лишилося, з підказкою про нерівний ритм чи повільний перехід;
- вправу завершено → наступна вправа або закріплення клавіші, на якій були виправлені помилки.

## Заняття на 15–25 хвилин

Сторінка «Заняття» складає план із чотирьох кроків: розігрів знайомою гамою, одна цільова навичка
(наступна вправа курсу), закріплення (адаптивна вправа на слабкі місця), справжній текст (слова з
відкритих клавіш або речення, якщо відкрито все).

## Діагностика та вибір рівня

Новий користувач обирає: почати з нуля, пройти хвилинну діагностику або відкрити все одразу.
Діагностика вимірює швидкість і точність на трьох реченнях і радить шлях за таблицею рівнів ТЗ.
